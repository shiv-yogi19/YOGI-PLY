Supported Formats & Browser Capabilities

Web Standard Playback: MP4 (H.264/AAC), WebM (VP8/VP9/AV1), OGV, and MOV (Safari/Apple platforms) play directly via hardware-accelerated HTML5 video decoders.

Adaptive Streaming (HLS & MPEG-DASH): HLS (.m3u8) is supported natively on iOS/Safari and dynamically loaded via Hls.js on MSE-compliant browsers. DASH (.mpd) is loaded dynamically via Dash.js on demand without inflating the base player bundle.

Legacy & Non-Web Containers: Formats like AVI, MKV, WMV, and FLV are legacy containers not supported natively by HTML5 web specifications. Yogi_PLY automatically diagnoses unsupported containers and provides actionable conversion recommendations instead of failing silently.

Screen Brightness Security Boundary: In compliance with browser sandboxing standards, mobile brightness gestures utilize a realtime CSS video filter (30% to 170%), as standard web pages cannot alter physical device hardware backlight.

Universal Embedding & Quickstart

1. Load via CDN (jsDelivr)

<!-- Yogi_PLY Liquid Glass Video Player Stylesheet --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/shiv-yogi19/Yogi_PLY@v1.0.0/dist/yogi-ply.min.css"> <!-- Yogi_PLY Universal Player Library --> <script src="https://cdn.jsdelivr.net/gh/shiv-yogi19/Yogi_PLY@v1.0.0/dist/yogi-ply.min.js"></script>

2. Zero-JS HTML Embed (Auto-Initialization)

<div class="yogi-ply" data-video="https://example.com/movie.mp4" data-poster="https://example.com/poster.jpg" data-theme="liquid-glass" data-watermark="true"> </div>

3. Programmatic JavaScript Initialization

const player = new YogiPLY.Player('#my-player', { source: 'https://example.com/video.mp4', poster: 'https://example.com/poster.jpg', theme: 'liquid-glass', watermark: { enabled: true, text: 'Created By Shiv Yogi', opacity: 0.28, interval: 12000 }, subtitles: [ { label: 'English', src: '/subs/en.vtt', default: true } ] }); player.on('play', () => console.log('Playing!'));
